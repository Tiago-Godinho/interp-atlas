# Interp Atlas

A 3D, scroll-driven tour of how researchers read and steer neural networks: neurons, superposition, sparse autoencoders, the logit, tuned and Jacobian lenses, and activation steering. Every figure is computed from open models (GPT-2 small, Qwen3-1.7B, InceptionV1) or from small models trained live in your browser.

**Read it:** https://tiago-godinho.github.io/interp-atlas/

This repository holds only the built site. The papers and data behind each figure are listed under *Sources* on the site.

Fonts: Schibsted Grotesk and glyphs from the Noto fonts (SIL Open Font License 1.1); KaTeX fonts (MIT licence).
